# EventHub-Web-Application

EventHub is a web application that allows users to create, manage, discover, and reserve events. The platform includes event creation, ticket reservations, event tagging, search functionality, and database-backed storage.

This repository showcases my contributions to a university software engineering project completed as part of the CSS 360 Software Engineering course. My work focused on implementing event tagging functionality, integrating tags into the event creation process, and enhancing event organization features. Through this project, I gained experience with Java, Spring Boot, React, Docker, GitHub, pull requests, code reviews, and collaborative software development.

## Author

- April French

## Technology Stack

- Backend: Spring Boot 3.2.0 with Java 17
- Database: H2
- Frontend: React 18
- Containerization: Docker & Docker Compose

## Features

- Create and manage events
- Reserve event tickets
- Event tagging and organization
- REST API for event and reservation management
- Persistent database storage
